FAQ

Which simulators are supported?

Any simulator that supports standard USB gamepad input, including popular FPV simulators.

Do I need drivers?

No special driver is required. AK SimLink appears as a USB HID gamepad.

Can I update firmware myself?

Yes. Firmware updates are done through the browser using the AK SimLink updater.

Which one should I buy?

Choose Lite for ELRS only. Choose Pro if you want ELRS, Crossfire, FrSky and onboard screen features.

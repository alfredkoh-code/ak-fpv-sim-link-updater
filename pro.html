📖 AK SimLink Pro Firmware Update Guide
⚠ IMPORTANT

For AK SimLink Pro, please use the Read Device Version button first if the device is already running firmware that supports version reading. If the version cannot be read, you can still enter bootloader mode manually and flash the latest firmware.

Step 1 — Connect the UPDATE USB Port

  1. Connect AK SimLink Pro to your PC using the UPDATE USB port.
  2. Wait for the device to power on.
  3. Click Read Device Version.
  4. Select the COM port when prompted by your browser.
  5. The updater will display your current firmware version and compare it with the latest available version.

Step 2 — Install Firmware

  1. Select the firmware version you wish to install.
  2. Click INSTALL.
  3. Select the same COM port.
  4. Wait until the installation is complete.
  5. Do not disconnect the USB cable during the update.

Step 3 — Verify Firmware

  1. After the installation is complete, wait for the device to restart.
  2. Click Read Device Version again.
  3. Confirm that the displayed firmware version matches the installed version.

Step 4 — Restart and Verify

  1. After flashing is complete, unplug and reconnect AK SimLink Pro normally.
  2. Wait for the screen to boot into the main interface.
  3. Click Read Device Version again to confirm the update.
  4. You can also check the version on the Pro device screen if your firmware displays it in Device Info.
✔ Update Complete

Your AK SimLink Pro is now updated. If the device does not start normally after flashing, unplug it, wait a few seconds, and reconnect it without holding any button.

Useful Tips

  1. Use a direct USB port on the PC. Avoid USB hubs during updates.
  2. Use a data-capable USB cable. Charging cables may not work.
  3. If no COM port appears, try another cable or USB port.
  4. If flashing fails halfway, enter bootloader mode and try again.
  5. Make sure you are on the Pro updater page, not the Lite updater page.

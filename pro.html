📖 AK SimLink Pro Firmware Update Guide
⚠ IMPORTANT

For AK SimLink Pro, please use the Read Device Version button first if the device is already running firmware that supports version reading. If the version cannot be read, you can still enter bootloader mode manually and flash the latest firmware.

Step 1 — Check Current Firmware Version

  1. Plug your AK SimLink Pro into your PC normally.
  2. Click Read Device Version on this page.
  3. Select the correct COM port when the browser asks.
  4. If successful, the page will show your current device version and compare it with the latest firmware.
  5. If it shows Read Failed or NO RESPONSE, continue with manual bootloader update below.

Step 2 — Enter Bootloader Mode

  1. Disconnect the USB cable from AK SimLink Pro.
  2. Press and hold the ENTER button.
  3. While holding the ENTER button, plug the USB cable into your PC.
  4. Release the ENTER button after the USB is connected.

Step 3 — Install Firmware

  1. Select the firmware version below.
  2. Click the INSTALL button.
  3. Select the correct COM port.
  4. Follow the browser flashing instructions.
  5. Do not disconnect the USB cable during flashing.

Step 4 — Restart and Verify

  1. After flashing is complete, unplug and reconnect AK SimLink Pro normally.
  2. Wait for the screen to boot into the main interface.
  3. Click Read Device Version again to confirm the update.
  4. You can also check the version on the Pro device screen if your firmware displays it in Device Info.
✔ Update Complete

Your AK SimLink Pro is now updated. If the device does not start normally after flashing, unplug it, wait a few seconds, and reconnect it without holding any button.

Useful Tips

  1. Use a direct USB port on the PC. Avoid USB hubs during firmware updates.
  2. Use a data-capable USB cable. Some charging cables cannot flash firmware.
  3. If no COM port appears, try another cable or another USB port.
  4. If flashing fails halfway, repeat bootloader mode and install again.
  5. Make sure you are on the Pro updater page, not the Lite updater page.
